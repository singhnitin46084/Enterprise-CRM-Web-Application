# Enterprise CRM Web Application

A robust Enterprise Customer Relationship Management (CRM) platform built using Java, Spring Boot, Spring Security, Hibernate ORM, Thymeleaf, and MySQL.

## Key Features
- **Role-Based Access Control (RBAC):** Configured with Spring Security for `ADMIN` and `MANAGER` roles (Admin has deletion privileges; Managers have read/write access).
- **Comprehensive CRUD Operations:** Complete lifecycle tracking for enterprise accounts and leads.
- **Dynamic Search & Multi-criteria Filtering:** High-efficiency data retrieval across first name, last name, company, email, and pipeline stage.
- **Persistent Relational Architecture:** MySQL schema mapped using JPA/Hibernate entities with validation rules.

## Tech Stack
- **Backend:** Java 17, Spring Boot 3, Spring Data JPA, Spring Security
- **Frontend:** Thymeleaf, HTML5, Bootstrap 5
- **Database:** MySQL 8.0
- **Build Tool:** Maven
